  [CRITICAL DEFECT UX-01] : 403 DEAD-END ON UNLINKED SUPER ADMINISTRATOR
  ───────────────────────────────────────────────────────────────────────────────────────────────
  • Location : Left Sidebar Navigation -> "Me" Group (/me, /me/documents, /me/training, etc.)
  • Observation :
    When user "cedi" (logged in as Super Administrator) clicks on 7 of the 10 self-service
    links in the sidebar, the server returns an unhandled HTTP 403 Forbidden page:
    "403 — Your account is not linked to an employee record. Ask your administrator to link it."
  • UX Friction :
    1. The user IS the administrator; advising them to "ask your administrator" is circular.
    2. Primary navigation should never lead directly into hard HTTP 403 error screens.
  • Recommended Solution :
    1. Check employee profile link status on session creation.
    2. If unlinked, either hide the self-service group or display a "(Not Linked)" badge.
    3. Replace the raw 403 page with an in-app banner offering a 1-click "Link Account" wizard.

  [CRITICAL DEFECT UX-02] : MANUAL ISO-2 NATIONALITY DATA ENTRY
  ───────────────────────────────────────────────────────────────────────────────────────────────
  • Location : Add Employee Form (/employees/create) -> Nationality Field
  • Observation :
    The field is rendered as a raw 2-character text input:
    <input class="hx-input" type="text" name="nationality" maxlength="2" value="QA">
  • UX Friction :
    HR staff are required to know 2-letter ISO 3166-1 alpha-2 codes. Users attempting to type
    "Qatar" or "Philippines" get cut off at "Qa" or "Ph", leading to failed submissions.
  • Recommended Solution :
    Replace the text field with a searchable select dropdown containing full country names and
    flags (e.g., "Qatar (QA)", "Philippines (PH)", "India (IN)").

  [MAJOR DEFECT UX-03] : DESTRUCTIVE ACTIONS USE NATIVE BROWSER CONFIRMATION
  ───────────────────────────────────────────────────────────────────────────────────────────────
  • Location : Global Client Interactions (helix.js line 44)
  • Observation :
    Destructive actions execute window.confirm(el.dataset.hxConfirm).
  • UX Friction :
    Native browser dialogs freeze the thread, look inconsistent across operating systems, and
    cannot be styled to match the dark cybersecurity theme.
  • Recommended Solution :
    Replace window.confirm with an accessible modal dialog containing styled "Confirm" (red)
    and "Cancel" (ghost) buttons.

  [MAJOR DEFECT UX-04] : MISSING USER PROFILE DROPDOWN MENU
  ───────────────────────────────────────────────────────────────────────────────────────────────
  • Location : Header Utility Bar (hx-topbar)
  • Observation :
    The top bar renders flat ghost buttons in a row: Language, Notifications, 2FA setup, Logout.
  • UX Friction :
    No visual display of the active user's identity or avatar. 2FA setup text creates visual
    crowding on tablet viewports.
  • Recommended Solution :
    Consolidate utility controls into a single User Profile Dropdown menu in the top-right:
    [ Cedric Regis JR ▾ ] -> Super Administrator | 2FA (Off) | Language | Sign Out.

  [MAJOR DEFECT UX-05] : PASSIVE EMPTY STATES WITHOUT DIRECT CALL-TO-ACTION
  ───────────────────────────────────────────────────────────────────────────────────────────────
  • Location : Tables with Zero Records (/leave, /attendance, /approvals, /assets)
  • Observation :
    Empty states display explanatory copy (e.g., "No leave requests found") but provide no
    button inside the card.
  • UX Friction :
    Forces users to scan away from the content area to locate the header action button.
  • Recommended Solution :
    Add a prominent "+ Create / Apply" button directly inside every empty-state container.


┌──────────────────────────────────────────────────────────────────────────────────────────────────┐
│ 4. ACCESSIBILITY (WCAG 2.1 AA) & RESPONSIVE COMPLIANCE                                           │
└──────────────────────────────────────────────────────────────────────────────────────────────────┘

  • Form Input Labeling : Checkboxes in Attendance, Recruitment, and Training lack explicit
    for/id label bindings. Screen readers cannot properly announce field purposes.
  • Mobile Drawer Trapping : When the sidebar drawer opens on screens < 960px, keyboard focus
    is not trapped within the drawer, allowing users to tab behind the overlay.
  • Contrast Verification : The brand palette achieves strong contrast ratios (>8:1 for body
    text and headings). Accent violet (#B55CDB) should be slightly brightened to #C776EC on
    secondary surfaces to maintain full WCAG AA compliance.
  • Viewport Scaling :
    - Desktop (1280px+)  : Excellent. Balanced cards, clear tables, and generous spacing.
    - Tablet (768px-960px): Good. Navigation collapses cleanly into a hamburger drawer.
    - Mobile (<480px)    : Adequate. Multi-column tables require horizontal scrolling;
                           transforming records into card stacks will significantly boost UX.
